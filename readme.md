# AI Learning Insight

AI Learning Insight merupakan Capstone Project dari Program Asah 2025 yang dipimpin oleh Dicoding dan Accenture.

---

AI Learning Insight berguna untuk menunjukkan wawasan (Insight) terkait gaya belajar siswa menggunakan model machine learning dan disajikan dengan React dan data yang disimpan di SQL Database Postgre melalui Supabase dan Supabase Object storage.

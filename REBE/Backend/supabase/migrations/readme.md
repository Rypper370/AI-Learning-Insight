# Supabase Project Setup

Change this in your Supabase project settings! Or else it won't work!

## User Signups

- Allow new users to sign up: ✅ Enabled
- Allow manual linking: ❌ Disabled
- Allow anonymous sign-ins: ❌ Disabled
- Confirm email before first sign-in: ❌ Disabled

## Auth Providers

- Email: ✅ Enabled
- Phone: ❌ Disabled
- SAML 2.0: ❌ Disabled

After that, feel free to import the migration to setup proper tables.
